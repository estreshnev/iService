# iService35.ru - Project Context

## Project Overview
A **premium, visually stunning** website for iService35.ru - a service company with multiple office locations. Focus on beautiful design, smooth animations, and exceptional user experience.

## Goals
- Create a **beautiful and premium** multi-page website
- Showcase company services with elegant design
- Provide easy access to pricing information
- Enable users to find office locations via interactive map
- Impress visitors with smooth animations and transitions
- Stand out with modern, high-end aesthetic

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **CSS Framework**: Tailwind CSS / Bootstrap 5 (modern utility-first approach)
- **Animations**: GSAP (GreenSock), AOS (Animate On Scroll), or Anime.js
- **Icons**: Font Awesome Pro / Feather Icons / Lucide Icons
- **Fonts**: Google Fonts (premium typography combinations)
- **Additional Libraries**:
  - Swiper.js (premium sliders/carousels)
  - Particles.js / Three.js (background effects if needed)
  - Typed.js (typing animations)
  - CountUp.js (number animations)
- **Maps**: Yandex Maps API with custom styling
- **Development**: VSCode + Claude Code
- **Hosting**: reg.ru

## Key Features

### 1. Landing Pages
- **Home page** - Hero with animations, parallax effects, premium sections
- **Services page** - Beautiful service cards with hover effects
- **About page** - Company story with timeline/animations
- **Contact page** - Elegant contact forms and information
- Each page with **premium, eye-catching design**
- Smooth page transitions
- Scroll-triggered animations

### 2. Yandex Maps Integration
- Interactive map showing all office locations
- Custom-styled markers for premium look
- Animated info windows with office details (address, phone, hours)
- Custom map styling to match brand colors

### 3. Price Calculator Form
- Beautiful, interactive JavaScript form
- Dynamic price calculation with smooth animations
- Premium UI with elegant transitions
- Advanced form validation with helpful feedback
- Animated results display
- Micro-interactions for better UX

## Target Audience
- Local customers looking for services
- People searching for office locations
- Users wanting price estimates

## Design Principles
- **Premium & luxurious** - High-end aesthetic that impresses
- **Smooth animations** - GSAP/AOS for delightful interactions
- **Modern typography** - Carefully selected font pairings
- **Color harmony** - Professional color palette with gradients
- **Mobile-responsive** - Beautiful on all devices
- **Performance** - Fast loading despite rich animations
- **Intuitive navigation** - Smooth, easy to use
- **Attention to detail** - Micro-interactions, hover effects, transitions
